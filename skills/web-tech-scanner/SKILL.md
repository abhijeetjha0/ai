# Web Tech & Package Scanner

## Overview
This skill empowers an AI agent to analyze any production or development website URL, reverse-engineer the underlying frontend dependencies and NPM packages, and generate a comprehensive Technology Stack Audit Report.

The scanner discovers packages dynamically through:
1. **Source Map Mining**: Deep parsing of public `.map` files to extract exact `node_modules/@scope/pkg` paths.
2. **Bundler License Manifests**: Automatically probing companion `.LICENSE.txt` files and header comments (`/*! @license ... */`) generated by Webpack, Vite, and esbuild.
3. **Hydration & Structural Introspection**: Detecting modern meta-frameworks (Next.js, Nuxt, Astro, Remix, Vite) and component primitives (Radix UI, Tailwind CSS, MUI).
4. **Agentic Knowledge Synthesis**: The AI agent classifies and explains any discovered package on the fly using its own comprehensive software engineering knowledge.

---

## Prerequisites & Tools
- **Node.js**: `v18+` must be available to run the bundled scanner script.
- **Tools**:
  - `ask_question`: To present the ingestion options to the user.
  - `run_command`: To execute `curl` commands and the local detection engine (`scripts/scan-webpage.js`).
  - `chrome-devtools` or `browser_subagent`: To read the active Chrome browser tab, inspect live SPAs, and extract runtime window globals.
  - `read_url_content`: Fallback tool to fetch static HTML content directly if shell networking is constrained.
  - `write_to_file`: To output the final tech stack audit report.

## Mandatory Execution Protocol

### Step 1: Mandatory Entrypoint Prompt (Never Skip!)
Every time this skill is invoked, the AI agent **MUST NOT** make assumptions or scan an existing page automatically.
The agent **MUST** present the user with the ingestion choices via `ask_question`:

1. **Scan Active Chrome Browser Tab**: Reads the currently open website in Chrome, queries live runtime globals, and runs the audit instantly.
2. **Direct URL Input**: Enter a target website URL directly in chat.
3. **Terminal `curl` / Webfetch**: Headless CLI fetch and pipeline into scanner.
4. **Local File Scan**: Scan a local HTML file (e.g. `index.html`).

---

### Step 2: Ingestion & Execution Rules

#### Option A: Scan Active Chrome Browser Tab (SPAs & Live Sessions)
For Single Page Applications, authenticated pages, or when the user is browsing in Chrome:

1. **Identify the Active Tab**:
   - Call `list_pages` via `chrome-devtools-mcp` to get the current URL and page ID.
   - Confirm the target URL with the user or proceed if they requested scanning the active tab.
2. **Inspect Runtime Globals**:
   - Call `evaluate_script` to check runtime globals directly:
     ```javascript
     () => ({
       url: window.location.href,
       title: document.title,
       globals: {
         next: !!window.__NEXT_DATA__,
         nuxt: !!(window.__NUXT__ || window.__NUXT_DATA__),
         react: !!(window.React || window.__REACT_DEVTOOLS_GLOBAL_HOOK__),
         vue: !!(window.Vue || window.__VUE__),
         angular: !!(window.angular || window.ng),
         lodash: !!window._,
         gsap: !!window.gsap,
         three: !!window.THREE
       }
     })
     ```
3. **Extract Live Hydrated DOM & Run Scanner**:
   - Extract `document.documentElement.outerHTML` and feed it into `scan-webpage.js --stdin`:
     ```bash
     node skills/web-tech-scanner/scripts/scan-webpage.js "<CURRENT_URL>" --stdin --output under-evaluation/web-scan-reports/scan-data.json
     ```

---

### Step 3: Automated Dynamic Tech & NPM Package Detection

The scanner script discovers technologies and dependencies dynamically:
- **Dynamic Source Map Mining**: Analyzes `.map` files (via `sources` arrays) to extract any and all `node_modules/` dependencies with 100% precision.
- **Companion Bundler License Manifests**: Probes `.LICENSE.txt` files and header comments (`/*! @license ... */`) automatically generated by Webpack, Vite, and esbuild.
- **Architectural & Meta-Framework Probes**: Detects runtime frameworks (Next.js, Nuxt, Astro, Remix, Vite) and core design systems (Radix UI, Tailwind CSS, MUI, AntD) via structural DOM and hydration markers.
- **In-Memory Agentic Categorization**: The AI agent classifies discovered packages (Framework, State Management, UI Primitives, Animation, Analytics) dynamically.

---

### Step 4: Report Generation & Presentation

1. Read the report template from `resources/report-template.html`.
2. Populate the placeholders (`{{TARGET_URL}}`, `{{TOTAL_PACKAGES}}`, `{{PACKAGE_ROWS}}`, `{{SOURCE_MAP_STATUS}}`, etc.) with the scan findings.
3. Save the final report to `under-evaluation/web-scan-reports/report.html`.
4. Provide the user with a concise summary in chat:
   - High-confidence detected NPM packages and frameworks.
   - UI design system, CSS framework, and utility libraries detected.
   - Clickable markdown link to the saved HTML audit report.

## Best Practices & Guidelines
- **Always Prompt First**: Never scan an existing tab without presenting options to the user.
- **Direct Tab Inspection Over Injected DOM**: Do not inject temporary buttons into the webpage DOM, as navigation resets the DOM. Instead, read the active Chrome tab's state directly via DevTools MCP tools.
- **Dynamic Discovery**: Rely on source maps, license manifests, and runtime artifacts for scalable package identification.
- **Focus Strictly on Technology Identification**: Do not scrape or copy component code.
